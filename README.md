# Little Red Bird Publishing

Welcome to the repository for the **Little Red Bird Publishing** website! This is a modern, responsive React application built to showcase boutique publishing services, author portfolios, and submission guidelines for the _Dark Speculations_ anthology.

---

## 🌟 Features

- **Dynamic Portfolio:** A highly interactive, filterable gallery of published works dynamically rendered from a local data file.
- **Service Breakdown:** Comprehensive outlines of Book Coaching, Developmental Editing, and Full-Service Self-Publishing, complete with embedded explainer videos and FAQs.
- **Dark Speculations Portal:** An immersive, atmospheric landing page detailing submission guidelines, formatting rules, and direct email integration for the horror anthology.
- **Affiliates Hub:** A curated, visual list of recommended writing and publishing tools with direct referral links.
- **Live Contact Form:** Seamlessly integrated with Formspree to handle client project inquiries instantly and securely without a backend server.

---

## 🛠️ Tech Stack

- **Framework:** React
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Form Handling:** Formspree
